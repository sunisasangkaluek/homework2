# 🌱 FoodLink: เชื่อมโยงส่วนเกินอาหารสู่ชุมชน
**(แก้ปัญหาขยะอาหารและภาวะความยากจน | Zero Food Waste × Zero Hunger)**

**FoodLink** เป็นเว็บแอปพลิเคชันตัวกลางที่เชื่อมโยง **ร้านอาหาร ซูเปอร์มาร์เก็ต โรงแรม และเบเกอรี่** ที่มีอาหารส่วนเกินคุณภาพดีแต่จำหน่ายไม่หมดในแต่ละวัน ให้สามารถลงประกาศ **แจกฟรี (บริจาค)** หรือ **จำหน่ายในราคาย่อมเยา (ลด 50–80%)** ให้กับมูลนิธิ ศูนย์พักพิง และประชาชนในชุมชนรอบข้างได้แบบเรียลไทม์

---

## ✨ ฟีเจอร์หลัก (Key Features)

1. **📡 ระบบแจ้งเตือนและอัปเดตแบบเรียลไทม์ (Real-Time Live Feed & Simulation)**
   - แสดงรายการอาหารส่วนเกินพร้อมเวลานับถอยหลังก่อนปิดรับ
   - มีระบบจำลองเหตุการณ์เมื่อร้านค้า/โรงแรมโพสต์อาหารใหม่เข้าสู่ระบบแบบสดๆ
2. **🗺️ เรดาร์แผนที่พิกัดอาหารและศูนย์พักพิง (Interactive Community Food Radar)**
   - แสดงหมุดพิกัดร้านค้าที่แจกฟรี ร้านค้าลดราคา และมูลนิธิที่กำลังต้องการอาหารในรัศมีพื้นที่ใกล้เคียง
3. **👥 รองรับการใช้งาน 3 บทบาท (Role Switcher)**
   - **🍲 ชุมชน / ประชาชนทั่วไป**: ค้นหาและจองสิทธิ์รับอาหารฟรี หรือซื้ออาหารลดราคา 50–80%
   - **🏠 มูลนิธิ / ศูนย์พักพิง**: เบิกรับอาหารบริจาคล็อตใหญ่ (Bulk Donation) พร้อมประสานอาสาสมัคร FoodLink Rider จัดส่งฟรี
   - **🏪 ร้านค้า / โรงแรม / ซูเปอร์มาร์เก็ต**: ลงประกาศส่งต่ออาหารส่วนเกิน หรือจับคู่บริจาคตรงให้ศูนย์พักพิงที่ขาดแคลน
4. **🎟️ คูปอง QR Code รับอาหาร (Instant Pickup Pass)**
   - ออกรหัสรับอาหาร (`FL-XXXXXX`) ทันทีหลังยืนยันการจอง เพื่อนำไปแสดงที่หน้าร้านหรือส่งต่อให้อาสาสมัคร
5. **🌍 แดชบอร์ดวัดผลความยั่งยืน (Social & Environmental Impact Dashboard)**
   - คำนวณจำนวนมื้ออาหารที่ช่วยไว้, ปริมาณขยะอาหารที่ลดได้ (กิโลกรัม), ปริมาณก๊าซเรือนกระจกที่ลดได้ ($\text{kg CO}_2\text{e}$) และมูลค่าค่าครองชีพที่ช่วยประหยัดได้ (บาท)

## 🚀 วิธีใช้งาน (Getting Started)

สามารถเปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์สมัยใหม่ (Chrome, Edge, Firefox, Safari) เพื่อใช้งานได้ทันทีโดยไม่ต้องติดตั้งไลบรารีเพิ่มเติม

### โครงสร้างไฟล์
- `index.html` — โครงสร้างหน้าเว็บแอปพลิเคชันและหน้าต่างโมดอล (`<dialog>`)
- `styles.css` — สไตล์และการจัดวางแบบ Responsive
- `app.js` — ลอจิกการทำงาน ระบบกรองข้อมูล การจำลองเรียลไทม์ และการบันทึกข้อมูลลง `localStorage`
